# 基础配置

## 端口设置

默认监听端口为 `10000`，可在应用主页的配置卡片中修改。

修改端口后服务会自动重启。已连接的 ADB 客户端需要重新 `adb connect`。

> 端口号范围为 `1024–65535`，低于 `1024` 的端口需要系统权限，不建议使用。

## 局域网模式

默认情况下 TCP 服务仅监听 `127.0.0.1`（本地回环），只有设备本机可以连接。开启**局域网模式**后，服务会监听 `0.0.0.0`，同局域网内的其他设备可以通过设备 IP 连接。

### 适用场景

| 场景 | 建议 |
|------|------|
| 设备本机调试 | 关闭局域网模式（默认），更安全 |
| 电脑通过 ADB 控制手机 | 开启局域网模式 |
| 自动化框架（如 MAA）连接模拟器 | 模拟器场景通常不需要局域网模式 |

### 连接方式

```shell
# 先查设备局域网 IP
adb -s 127.0.0.1:10000 shell ip addr show wlan0
# 或
adb -s 127.0.0.1:10000 shell ifconfig wlan0

# 用 IP 连接
adb connect 192.168.1.100:10000
```

## 安全与 IP 过滤

开启局域网模式后，服务会通过 **IP 地址过滤** 限制接入来源，仅允许以下三类私网地址：

| 类别 | 地址范围 | 典型场景 |
|------|----------|----------|
| A 类 | `10.0.0.0/8` | 大型企业内网 |
| B 类 | `172.16.0.0/12` | 中型企业内网 |
| C 类 | `192.168.0.0/16` | 家庭/小型局域网 |

### 安全机制说明

- 公网 IP 的连接请求会被直接拒绝，不会进入 ADB 协议握手阶段
- `/8` 环回地址（`127.0.0.0/8`）仅允许本地回环
- 链路本地地址（`169.254.0.0/16`）也被允许但实践中极少使用

### 重要安全提醒

**不要在公网或端口映射环境下暴露此服务。** 原因：

1. **ADB 协议本身不加密**，所有传输的数据（包括截图、输入事件）均为明文
2. IP 过滤仅检查来源地址，不提供身份认证
3. 如果将设备端口映射到公网，任何知道 IP 和端口的人都可以连接你的设备

> 如果你需要通过公网访问，建议使用 SSH 隧道、WireGuard 或 Tailscale 等加密隧道方案，而不是直接暴露端口。

### 排查连接被拒

如果连接被拒绝，常见原因：

```shell
# 检查服务是否在监听
adb -s 127.0.0.1:10000 shell netstat -tln | grep 10000

# 检查设备 IP
adb -s 127.0.0.1:10000 shell ip addr show wlan0

# 确保电脑和设备在同一局域网
ping <设备IP>
```
