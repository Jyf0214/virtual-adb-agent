### 三、 局域网绑定功能（`0.0.0.0:10000`）风险告知

本软件提供可选的局域网监听扩展功能：

1. **功能说明**：当您主动在设置中开启局域网绑定选项时，本软件的服务地址将从本地环回转换为局域网全网卡绑定（即 `0.0.0.0:10000`）。
2. **安全风险提示**：
   * 开启此功能后，**同一局域网（同一 Wi-Fi 或路由器网络）内的任何其他设备**均可通过 `adb connect <您的手机IP>:10000` 连接至本软件。
   * 处于同一局域网的设备将拥有向您的手机发送触控指令、获取屏幕截图的权限。
   * **本软件不实施 ADB RSA 密钥对认证或密码校验**。连接后客户端可直接发送指令，无需额外配对流程。
3. **内置来源 IP 过滤**：为降低安全风险，本软件在局域网模式下**自动拒绝所有来自外部公网 IP 的连接**。仅允许以下地址段接入：
   * `127.0.0.1` — 本地设备自身
   * `10.x.x.x` — 局域网 A 类地址
   * `172.16.x.x ~ 172.31.x.x` — 局域网 B 类地址
   * `192.168.x.x` — 局域网 C 类地址
   * 任何不在此范围内的公网 IP 连接将在 TCP 握手后**立即被拒绝并关闭连接**。
4. **内网穿透与端口映射风险（重要）**：
   * 即使本软件具备来源 IP 过滤机制，**如果您或您的网络管理员在路由器上设置了端口映射（Port Forwarding）或使用了内网穿透工具（如 frp、Ngrok 等），仍然可能将本服务暴露至公网**。
   * 在此情况下，经过映射后的公网流量会在 TCP 层面到达本软件，但来源 IP 被过滤后**连接仍会被拒绝**。
   * **开发者强烈建议：** 非必要请勿启用局域网绑定功能。日常使用请始终保持在默认的本地环回模式（`127.0.0.1`）下运行。请勿主动对本软件使用的端口进行端口映射或内网穿透配置。
5. **用户责任**：
   * 您在开启此功能前，必须确保当前处于安全、可信的局域网环境（如公共 Wi-Fi 环境下强烈建议关闭此功能）。
   * **因您故意配置端口映射或内网穿透导致的任何安全后果，由您自行承担。**

您有权随时在系统设置中撤销上述权限，但撤销权限后本软件的相关代理功能将无法正常运行。
