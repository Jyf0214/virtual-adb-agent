# Virtual ADB Agent 隐私政策

**更新日期**：2026 年 7 月 29 日  
**生效日期**：2026 年 7 月 29 日

**Virtual ADB Agent**（以下简称"本软件"）由个人开发者 Jyf0214（以下简称"开发者"）开发。开发者深知个人信息对您的重要性，并高度重视您的隐私保护。

本《隐私政策》（以下简称"本政策"）旨在向您说明本软件如何处理您的数据与系统权限。**本软件不设任何云端服务器，绝不向开发者或任何第三方云端传输或收集您的任何个人身份信息或设备隐私数据。**

---

### 一、 我们如何收集和使用您的信息

**结论：本软件不收集、不存储、不上传您的任何个人信息。**

1. **个人身份信息**：本软件不需要您注册账号，不读取您的手机号、姓名、身份证号、通讯录、短信或通话记录。
2. **设备标识与网络数据**：本软件不读取 IMEI、MAC 地址、Android ID 等敏感设备标识符，亦不会主动收集或追踪您的外网 IP 地址。
3. **应用使用数据**：本软件无任何统计分析 SDK，不追踪您的使用习惯或操作日志。

---

### 二、 系统权限的申请与使用目的

为了在您本地或局域网设备上提供虚拟 ADB 代理服务，本软件需要在运行时向您申请以下权限：

| 申请权限 | 使用目的说明 | 隐私防护承诺 |
| :--- | :--- | :--- |
| **无障碍服务 (Accessibility)** | 用于接收并执行来自您授权客户端发出的触控操作指令（如模拟点击、模拟滑动）。 | **绝不读取** 您的屏幕文本、密码输入框、通知内容或任何界面隐私数据。 |
| **屏幕录制权限 (MediaProjection)** | 用于响应来自您授权客户端发出的截图请求（如 `screencap`），捕获当前屏幕图像并返回给客户端。 | 截图数据 **仅在内存中动态传输**，绝不上传至任何互联网云端服务器。 |
| **前台服务权限 (Foreground Service)** | 用于保障本软件后台服务的稳定性，避免服务被系统挂起。 | 仅用于保障服务常驻，不收集任何数据。 |

您可以随时在系统的"设置 - 权限管理"或"无障碍"中撤销授权，但这将导致本软件无法提供对应的代理服务。

### 三、 数据存储与网络传输机制

1. **本地配置持久化存储**：本软件的部分配置项（如监听端口、智能缩放、截图质量等）通过 Android 本地 `SharedPreferences` 持久化存储在您的设备本地，App 重启后仍保持。
2. **临时状态说明**：以下两项配置为**运行时临时状态**，不会持久化，App 重启或进程被杀后自动恢复为默认值：
   * **局域网模式开关**：每次启动默认为关闭（仅本地 `127.0.0.1` 环回），这是出于安全考虑，避免用户在不知情的情况下暴露服务。
   * **屏幕录制授权状态**：Android 系统机制决定了 MediaProjection 授权无法跨进程持久化，每次 App 进程重启后需重新授权。
3. **网络传输模式**：
   * **默认模式（本地环回 `127.0.0.1:10000`）**：所有数据传输严格限制在您当前手机设备内部的应用程序之间，数据绝不离开您的手机。
   * **可选模式（局域网绑定 `0.0.0.0:10000`）**：若您主动开启此功能，数据将在您所在局域网（如本地 Wi-Fi 网络）内的设备间传输。**即使在此模式下，数据传输也仅限于局域网内部，绝不向互联网上的任何云端服务器发送。**
4. **局域网连接安全机制**：
   * **来源 IP 自动过滤**：局域网模式下，本软件会自动检查每个 TCP 连接的来源 IP 地址。仅允许本地环回（`127.0.0.1`）及局域网私有地址（`10.x.x.x`、`172.16~31.x.x`、`192.168.x.x`）接入，**外部公网 IP 的连接会在握手后被立即拒绝并关闭**。
   * **无额外认证**：本软件不实施 ADB 标准 RSA 密钥对认证或密码校验，连接安全性依赖于网络隔离与 IP 过滤机制。请勿将本服务暴露于不可信网络环境中。
   * **防火墙提醒**：来源 IP 过滤对 TCP 层面的端口映射或内网穿透工具（如路由器端口转发、frp、Ngrok 等）透传的流量依然生效——经过映射的流量源 IP 会被识别为外部地址并被拒绝。但为安全起见，**强烈建议用户不要对本软件使用的端口进行任何端口映射或内网穿透配置**。

### 五、 未成年人隐私保护

1. **监护人同意**：如您为未成年人（特别是处于低龄或特定学习环境下的未成年人），在使用本软件前，必须在监护人指导下阅读本政策，并在取得监护人明确同意后方可使用。
2. **局域网功能使用提示**：监护人应注意，在开启局域网绑定功能（`0.0.0.0`）时，同一局域网下的其他设备均可连接本软件并获取屏幕截图。建议监护人在指导未成年人使用时，确保处于安全且受信的网络环境中。
3. **隐私安全**：因本软件不在云端收集或存储任何个人数据，因此不会产生未成年人云端个人信息泄露的风险。
