# 排错指南

## 连接问题

### `cannot connect to 127.0.0.1:10000`

**服务未启动。** 打开应用主页确认 TCP 服务状态是否为 **"运行中"**。如果没有，点击 **「启动服务」**。

### `connection refused`

**端口不匹配。** 确认应用中的端口号设置和 `adb connect` 使用的端口号一致。

### 局域网连接失败

排查步骤：

1. 确认应用已开启 **「局域网模式」**
2. 确认设备和电脑在同一局域网（`ping <设备IP>`）
3. 检查设备防火墙是否阻止了端口
4. 如果设备开启了 VPN，VPN 可能影响局域网通信
5. 部分路由器启用了 AP 隔离（Client Isolation），需要关闭

### 连接被拒绝（IP 过滤）

检查服务日志中是否有以下记录：

```
已拒绝公网连接：<你的IP>
```

说明你的连接来源 IP 不在私网地址范围内。可能原因：

- 开启了 VPN
- 通过公网 IP 或端口映射访问
- 使用了手机热点（部分热点的网络类型不是私网）

## 截图问题

### 截图全黑

常见原因：

- MediaProjection 权限已被系统回收。在应用主页重新点击 **「授权并启动」**
- 部分 OEM 系统（ColorOS、MIUI、HarmonyOS）结束后台 Activity 后权限会被清除
- 前台服务被杀。检查通知栏是否存在守护通知

### 截图模糊

默认开启了智能缩放。如果需要原始分辨率，可以尝试缩小目标区域或联系开发者。

### 截图很慢

高分辨率设备需要更多时间编码。建议：

- 减少应用频率
- 检查是否同时运行了多个截图请求（并发截图会排队处理）

## 手势问题

### 点击/滑动无反应

排查步骤：

1. 确认无障碍服务已开启：**设置 → 无障碍 → Virtual ADB Agent**
2. 确认无障碍服务的开关是**开启（绿色）**状态
3. 部分系统（HarmonyOS、ColorOS）在后台一段时间后会暂停无障碍服务，需要重新进入应用激活
4. 尝试执行一个简单命令如 `adb shell wm size` 确认服务本身在正常运行

### 按键事件不响应

`KEYCODE_POWER` 在多数设备上不响应——无障碍服务无法模拟电源键。`KEYCODE_HOME` / `KEYCODE_BACK` / `KEYCODE_APP_SWITCH` 在主流设备上正常工作。

## 断开与重连

### `StandaloneCoroutine was cancelled`

这是由于耗时的命令处理阻塞了 ADB 协议的消息读取循环。**1.0.x 及以上版本已修复此问题**，命令处理在独立协程中执行，不会阻塞读取循环。

如果仍然出现，请升级到最新版本。

### 频繁断开

可能原因：

- 设备进入深度睡眠。建议在开发者选项中开启 **"不保留活动"** 为关闭状态
- 系统杀死了前台服务。部分 OEM 系统允许用户一键清理时杀死前台服务
- 长时间无操作后系统回收了 MediaProjection 资源

## 其他

### 如何收集日志供排查

应用主页提供了两个日志面板：

1. **TCP 通信日志**：记录 ADB 协议消息（CNXN/OPEN/WRTE/CLSE）
2. **系统日志**：记录应用内部运行状态和错误

两个面板都支持 **「一键复制」**，反馈问题时请提供系统日志。

### 开启调试截图

在应用主页开启 **「调试截图」**，每次 `screencap` 请求会同时保存原始截图到 `Downloads/` 目录，方便排查截图质量问题。
